M365 AiTM Phishing Defense Blueprint
Primary Defense: Phishing-Resistant MFA

Adversary-in-the-Middle reverse proxies (Evilginx2) transparently relay SMS and push MFA. Mandate FIDO2 WebAuthn Passkeys or Windows Hello for Business; the browser origin binding prevents credentials or session cookies from ever reaching fake proxy domains.

Entra ID Tenant Hardening:
  • Require Managed, Compliant Devices (Intune) for cloud resource access.
  • Enable Continuous Access Evaluation (CAE) to revoke stolen tokens on IP change.
  • Block user consent for unverified third-party OAuth multi-tenant applications.
Enterprise Ransomware Mitigation
3-2-1-1-0 Immutable Backups

Ensure at least one backup tier is completely offline or write-once-read-many (WORM / S3 Object Lock) to prevent threat actors from wiping backups during lateral movement.

Perimeter & Identity Hardening:
  • Disable external RDP (port 3389) and enforce Zero Trust Network Access (ZTNA).
  • Patch edge appliances (Citrix ADC, Fortinet, Ivanti Connect Secure) immediately.
  • Block PsExec and unauthorized remote PowerShell between workstation VLANs.
IoT Botnet Defense & DDoS Mitigation
Network Segmentation & Device Isolation

Place all smart cameras, DVRs, smart TVs, and IoT endpoints on an isolated, firewalled VLAN with no route to corporate subnets and blocked inter-device communication.

Device Hardening:
  • Disable Universal Plug and Play (UPnP) and Telnet (port 23) at the gateway router.
  • Replace all default administrative passwords (e.g. admin/admin) with 16+ character passphrases.
  • Enforce automated firmware updates and subscribe to vendor CSAF/VEX vulnerability feeds.
Infostealer & Drainer Countermeasures
Eliminate Browser Password Storage

Infostealers like Lumma and RedLine carve plaintext SQLite databases and decrypt Master Keys from %LOCALAPPDATA%\Google\Chrome\User Data\Local State via DPAPI. Migrate all credentials to dedicated, encrypted password managers (Bitwarden, 1Password) with hardware token master locks.

Web3 Security Best Practices:
  • Use hardware signing devices (Ledger, Trezor) that show destination addresses on a physical screen.
  • Utilize transaction simulation browser extensions (Wallet Guard, PocketUniverse) to detect malicious Drainer approval contracts.
