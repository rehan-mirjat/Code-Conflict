Key Privacy Regulations

GDPR

General Data Protection Regulation
Key Rights:
  • Right to access
  • Right to erasure
  • Data portability
  • Breach notification
Scope:

Applies to all EU citizens' data, regardless of company location

Since 2018 Fines up to 4% revenue

CCPA

California Consumer Privacy Act
Key Rights:
  • Right to know
  • Right to delete
  • Right to opt-out
  • Non-discrimination
Scope:

California residents, businesses with >$25M revenue or 50K+ users

Since 2020 $7500 per violation

PIPEDA

Personal Information Protection Act
Key Rights:
  • Consent requirements
  • Limited collection
  • Individual access
  • Accountability
Scope:

Canadian private sector organizations collecting personal data

Since 2000 Up to $100K fines

Data Privacy Checklist

  1. Review privacy settings on all accounts
  2. Enable two-factor authentication
  3. Use a password manager
  4. Opt-out of data broker lists
  5. Regularly delete unused accounts
  6. Use encrypted messaging apps
  7. Disable ad personalization
  8. Request data deletion from services

Data Removal Guides

Google Data

  1. Go to myactivity.google.com
  2. Click "Delete Activity By"
  3. Select date range or "All time"
  4. Choose which products to include
  5. Click "Delete"
Pro Tip: Set up auto-delete for future activity in Activity Controls

Facebook Data

  1. Go to Settings & Privacy → Settings
  2. Select "Your Facebook Information"
  3. Choose "Download Your Information"
  4. Select date range and data categories
  5. Create file and download when ready
Note: Deleting data doesn't delete your account - consider deactivation
