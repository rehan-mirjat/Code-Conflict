Security Checklist Recommended Extensions

Browser Security Levels

Maximum Security
  • HTTPS Everywhere extension
  • JavaScript disabled by default
  • All cookies blocked
  • VPN + Tor browser
Balanced Security
  • Ad/tracker blockers
  • Script blockers (selective)
  • First-party cookies only
  • Regular privacy sweeps
Minimum Security
  • No ad blocking
  • All cookies allowed
  • No script protection
  • HTTP connections
