What is Ransomware?

Ransomware is a type of malware that encrypts files or locks systems, demanding payment for decryption.

Typical Attack Flow:
  1. Initial infection (phishing, RDP brute force, exploit)
  2. Lateral movement through network
  3. Data exfiltration (in double extortion)
  4. File encryption
  5. Ransom demand

Common Ransomware Variants

LockBit
Ransomware-as-a-Service

Most active RaaS with automatic propagation and triple extortion tactics.

  • Targets: Enterprises
  • Encryption: AES-256 + RSA-2048
  • Extortion: Data leak + DDoS
REvil/Sodinokibi
Big game hunting

Affiliate program targeting large corporations with million-dollar ransoms.

  • Targets: Fortune 500
  • Encryption: Custom
  • Extortion: Auction data
Ryuk
Targeted attacks

Manual ransomware often deployed after TrickBot infection.

  • Targets: Healthcare, Govt
  • Encryption: RSA-4096
  • Extortion: Data theft

Ransomware Protection

Preventive Measures

  1. Backup Strategy
    3-2-1 rule (3 copies, 2 media, 1 offline)
    Essential
  2. Email Filtering
    Block executable attachments
    Critical
  3. Patch Management
    Critical updates within 72 hours
    High Priority

Incident Response

Disconnect infected systems from all networks immediately.

Use tools like ID Ransomware to identify the variant.

Wipe systems and restore from clean backups after eradication.
