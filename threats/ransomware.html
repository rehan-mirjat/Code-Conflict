What is Ransomware?

Ransomware is a type of malware that encrypts files or locks systems, demanding payment for decryption.

Typical Attack Flow:
  1. Initial infection (phishing, RDP brute force, exploit)
  2. Lateral movement through network
  3. Data exfiltration (in double extortion)
  4. File encryption
  5. Ransom demand

Common Ransomware Variants

LockBit
Ransomware-as-a-Service

Most active RaaS with automatic propagation and triple extortion tactics.

  • Targets: Enterprises
  • Encryption: AES-256 + RSA-2048
  • Extortion: Data leak + DDoS
REvil/Sodinokibi
Big game hunting

Affiliate program targeting large corporations with multi-million-dollar ransoms.

  • Targets: MSPs & Enterprise
  • Encryption: Salsa20 + ECDH (Curve25519)
  • Extortion: Auction dark web leak sites
Ryuk / Conti
Targeted enterprise hunt

Human-operated targeted ransomware deployed following Emotet/TrickBot lateral movement.

  • Targets: Healthcare, Govt, Education
  • Encryption: AES-256-CBC + RSA-4096
  • Extortion: Network paralysis & exfiltration

Ransomware Emergency Response Playbook

Sever physical network cables, disconnect Wi-Fi interfaces, and disable switch ports. Segment hypervisors, NAS shares, and Active Directory domain controllers. Switch all response team communications immediately to an out-of-band channel (e.g. Signal, dedicated clean cellular phones) as corporate email and Slack/Teams are often monitored by the adversary.

Do not hastily power off systems where encryption is ongoing or recently completed. Capture live memory triage images (using FTK Imager or LiME) on critical endpoints; cryptographic keys can sometimes be carved from memory processes before termination. Preserve firewall logs, NetFlow captures, and AD event logs before logs are rolled over or wiped.

Extract ransom notes, file extensions, and encrypted headers. Upload non-sensitive samples to ID Ransomware (id-ransomware.malwarehunterteam.com) and check the No More Ransom Project (nomoreransom.org) for official law-enforcement decryption tools (e.g., Operation Cronos LockBit 3.0 decryptors, REvil master keys).

Notify external legal counsel, cyber insurance carriers, and law enforcement (FBI IC3, CISA, Europol). For public companies, initiate SEC Item 1.05 Form 8-K disclosure assessments within mandatory 4 business day timelines, and evaluate GDPR/CCPA notification windows (72 hours) regarding exfiltrated PII.

Never restore directly onto compromised operating systems. Rebuild domain infrastructure from known-good baseline images. Verify backup integrity against the 3-2-1-1-0 rule (3 copies, 2 media types, 1 offsite, 1 immutable/air-gapped, 0 recovery errors) to ensure backups have not been poisoned by time-delayed malware sleeper logic.

LockBit 3.0 ("LockBit Black") Threat Profile
Attack Characteristics
  • Extensions: .lockbit / custom random 9-character hex (e.g., .HLJkNsk1P)
  • Ransom Note: README.txt / Restore-My-Files.txt
  • Encryption: Multi-threaded ChaCha20 + RSA session key wrapping
  • Initial Access: Stolen RDP/VPN credentials, CVE-2023-4966 (Citrix Bleed)
TTPs & Evasion

Re-uses code from BlackMatter/DarkSide. Employs reflection and anti-debugging tricks, disables Windows Defender via Group Policy tampering, and clears shadow copies with vssadmin.exe Delete Shadows /All /Quiet.

Decryption Status:

Operation Cronos (FBI, NCA, Europol, Feb 2024) seized leak sites and generated keys for specific LockBit 3.0 victims. Available via CISA and NoMoreRansom.

REvil / Sodinokibi Threat Profile
Attack Characteristics
  • Extensions: Random alphanumeric (e.g., .527xg2, .b019k)
  • Ransom Note: [random_ext]-readme.txt
  • Pioneer of: Double Extortion & Dark Web Data Auctions ("Happy Blog")
  • Famous Hits: JBS Foods ($11M paid), Kaseya VSA ($70M demand)
Exploit Methodology

Weaponized zero-days including CVE-2021-30116 in Kaseya VSA to bypass authentication and execute fake agent.exe updates deploying ransomware payloads simultaneously to downstream MSP customers.

Decryption Status:

Universal master decryption key was obtained by law enforcement and Bitdefender released an official decryptor for historical REvil victims prior to group disruption.

Ryuk / Wizard Spider Threat Profile
Attack Characteristics
  • Extensions: .RYK
  • Ransom Note: RyukReadMe.txt
  • Encryption: AES-256 (CBC mode) + RSA-4096 asymmetric key wrapper
  • Cartel: Wizard Spider (later evolved into Conti and BlackBasta)
Kill Chain Progression

Famous for the multi-stage "Triple Threat" attack chain: Phishing email -> Emotet payload delivery -> TrickBot/BazarLoader reconnaissance -> Cobalt Strike Beaconing -> Domain Admin escalation -> Mass Ryuk deployment.

Decryption Status:

No universal decryptor. Early variants had a key truncation bug fixable by Emsisoft, but standard Ryuk infections require immutable offline backup recovery.
