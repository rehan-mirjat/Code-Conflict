Password Attacks

Cybercriminals use various techniques to crack or steal passwords and gain unauthorized access to systems.

Attack Types Protection Guide

What Are Password Attacks?

Methods used by attackers to gain access to password-protected accounts by guessing, stealing, or cracking passwords.

Attack Flow:
  1. Attacker identifies target account
  2. Uses various techniques to obtain password
  3. Gains unauthorized access to system
  4. Escalates privileges or steals data

Password Attack Types

Brute Force Attack
Trying all possible combinations

Automated trial-and-error method that systematically checks all possible password combinations until the correct one is found.

Attack Speed:
1M+ attempts/second
Vulnerable Passwords:
  • Short passwords (under 8 characters)
  • Common patterns (123456, password)
  • No special characters
Dictionary Attack
Using common word lists

Uses a pre-arranged list of words (dictionary) to try against passwords rather than random combinations.

Common Dictionary Sources:
  • Top 10,000 most common passwords
  • Words from Wikipedia
  • Leaked password databases
  • Common phrases and patterns
"Summer2024!" can be cracked in 3 seconds
Credential Stuffing
Reusing leaked credentials

Uses username/password pairs exposed in data breaches to attempt logging into other services where users may have reused credentials.

Breach Statistics:
65%
Users reuse passwords
0.1%
Success rate
Even 0.1% success means 1M accounts from 1B attempts
Password Spraying
Few passwords, many users

Tries a small number of common passwords against many accounts to avoid account lockouts.

Common Spray Passwords:
  1. Winter2024!
  2. CompanyName123
  3. Welcome1
  4. Password1
  5. ChangeMe123
Attackers target cloud services (Office 365, G Suite)

How the Attack Works

Attack Flow:
  1. Attacker obtains leaked credentials from breaches
  2. Automates login attempts on banking sites
  3. Successful logins provide account access
  4. Funds transferred or accounts taken over
Protection Measures:
  • Never reuse passwords across sites
  • Enable multi-factor authentication (MFA)
  • Use a password manager
  • Monitor for unusual account activity
  • Check if your email appears in breaches

Password Protection Guide

Creating Strong Passwords

Do:
  • Use 12+ characters (longer is better)
  • Mix uppercase, lowercase, numbers, symbols
  • Consider passphrases (CorrectHorseBatteryStaple)
  • Use unique passwords for every account
Don't:
  • Use personal information (names, birthdays)
  • Repeat patterns (abc123, qwerty)
  • Reuse passwords across sites
  • Write passwords down unprotected

Advanced Protection

Multi-Factor Authentication (MFA)

Adds an extra layer of security beyond just a password. Even if your password is compromised, attackers can't access your account without the second factor.

Best Options: Authenticator apps (Google/Microsoft Authenticator) > SMS codes > Email codes
Password Managers

Generate, store, and autofill complex, unique passwords for all your accounts. You only need to remember one master password.

Recommended: Bitwarden, 1Password, KeePass, LastPass (with caution)
Account Monitoring

Enable login alerts and regularly check account activity for unauthorized access.

Brute Force Attack Details
Technical Implementation:

Brute force attacks typically use:

  • GPU acceleration (can try millions of combinations per second)
  • Rainbow tables (precomputed hash tables)
  • Distributed computing (botnets or cloud services)
Vulnerable Systems:
  • Systems without account lockout policies
  • Weak password hashing (MD5, SHA1)
  • No rate limiting on login attempts
Example: An 8-character password with only lowercase letters can be cracked in about 2 minutes with modern hardware.
