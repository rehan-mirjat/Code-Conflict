Microsoft 365 OAuth & AiTM Phishing Telemetry
Adversary-in-the-Middle (AiTM) MITRE ATT&CK T1566.002, T1528
Attack Telemetry Analysis

Adversaries deploy Evilginx2 reverse proxies behind Cloudflare tunnels. The victim visits a lookalike link (e.g. login.microsoftonline.corp-auth[.]net). The proxy passes legitimate login credentials and MFA push prompts to Microsoft servers, then intercepts and steals the resulting HTTP ESTSAUTH session cookie.

Consequence: The attacker injects the session cookie into their own browser, completely bypassing SMS and Authenticator app MFA without triggering a new login alert.

Defense-in-Depth Solutions:
  • Enforce FIDO2 WebAuthn Passkeys or Certificate-Based Authentication (CBA), which are cryptographically bound to the domain and cannot be proxied.
  • Configure Microsoft Entra ID Conditional Access with compliant device requirements and IP-location anomalous session token revocation.
  • Monitor Entra ID Audit logs for suspicious application consent grants (OAuth app permissions like Mail.ReadWrite or Files.ReadWrite.All).
LockBit 3.0 Threat Details
Overview

LockBit 3.0 is the latest version of the ransomware that operates as a Ransomware-as-a-Service (RaaS). It features:

  • Advanced anti-analysis techniques
  • Windows Defender bypass
  • Triple extortion tactics (encryption + data theft + DDoS)
  • Exploits PrintNightmare vulnerability
Protection
  1. Patch CVE-2021-34527 immediately
  2. Restrict RDP access
  3. Implement application whitelisting
  4. Backup air-gapped systems
  5. Train staff on phishing detection
Recent Activity

In the last 72 hours, LockBit 3.0 has:

  • Attacked 47 healthcare providers in North America
  • Demanded ransoms averaging $850,000
  • Published data from 12 victims on their leak site
